# Trapstalis

**Trapstalis** — лаунчер для загрузки, обновления и запуска игровых профилей Minecraft через инфраструктуру GML.

> **Важно:** этот репозиторий предназначен для распространения готовых сборок. Исходный код здесь не публикуется. Установочные архивы и обновления размещаются в разделе **[Releases](../../releases)**.

## Возможности

### Авторизация и аккаунт

- Вход в аккаунт по логину и паролю.
- Поддержка двухфакторной аутентификации (2FA) с кодом из приложения-аутентификатора.
- Просмотр игрового профиля, имени пользователя и доступного скина.

### Выбор сервера лаунчера

В лаунчере можно выбрать один из доступных backend-узлов:

- **RU1**
- **RU2**
- **PO**
- **MSK1**

Выбранный узел сохраняется локально. При смене backend лаунчер перезапускается и сбрасывает сохранённую сессию, чтобы не использовать токен, выданный предыдущим сервером.

### Игровые профили

- Получение списка доступных игровых профилей с сервера.
- Выбор нужной сборки и просмотр её версии, описания и статуса.
- Запоминание последнего выбранного профиля.
- Отображение суммарного количества игроков на игровых серверах.

### Загрузка, обновление и запуск Minecraft

- Автоматическая проверка игровых файлов перед запуском.
- Загрузка отсутствующих и обновление изменённых файлов.
- Проверка целостности файлов по хэшам.
- Отображение хода загрузки, количества обработанных/оставшихся файлов и текущей скорости загрузки.
- Проверка доступности необходимых компонентов запуска, включая Java.
- Запуск выбранного игрового профиля с учётом настроек лаунчера.

### Управление опциональными модами

Для профилей доступен список опциональных модификаций:

- просмотр названий и описаний модов;
- включение и выключение отдельных модификаций;
- загрузка файла мода, если он ещё отсутствует в папке профиля.

Набор доступных модификаций зависит от выбранного профиля и определяется сервером.

### Настройки игры и Java

- Ручной выбор объёма оперативной памяти.
- Настройка начального объёма памяти Java (`-Xms`) и максимального (`-Xmx`).
- Дополнительные пользовательские JVM-флаги и аргументы запуска игры.
- Изменение папки установки игровых файлов.
- Сохранение настроек между запусками.

### Новости и Discord

- Просмотр новостей проекта прямо в лаунчере.
- Интеграция с Discord Rich Presence: отображение статуса лаунчера и выбранной игры.

## Установка

1. Откройте страницу **[Releases](../../releases)**.
2. Скачайте архив последней версии для своей системы.
3. Распакуйте архив в отдельную папку.
4. Запустите исполняемый файл лаунчера.
5. Авторизуйтесь, выберите backend и игровой профиль, затем нажмите **«Играть»**.

Для первой авторизации и загрузки профиля требуется подключение к интернету. Убедитесь, что на диске достаточно свободного места для игровых файлов.

## Если лаунчер не подключается

1. Проверьте подключение к интернету.
2. Попробуйте выбрать другой доступный backend: RU1, RU2, PO или MSK1.
3. Используйте встроенную проверку доступности сервера.
4. Если проблема сохраняется, проверьте информацию к соответствующему релизу и сообщите об ошибке в **[Issues](../../issues)**, указав версию лаунчера и приложив текст ошибки.

При проблемах с запуском игры также проверьте выбранный профиль, свободное место на диске и выделенный объём оперативной памяти.

## Диагностика и данные

Лаунчер обращается к выбранному backend для авторизации, получения игровых профилей, новостей и файлов обновления. Данные действующей сессии сохраняются локально, чтобы не запрашивать вход при каждом запуске, пока сессия не истекла.

В приложении предусмотрена интеграция Sentry для отправки технических отчётов об исключениях, если диагностический endpoint предоставлен backend. Не следует считать, что приложение полностью работает без сетевых обращений.

## Обновления

Новые версии публикуются в разделе **[Releases](../../releases)**. Перед установкой обновления закрывайте лаунчер. Изменения конкретной версии указываются в описании релиза.
